The Extreme Value Theorem

In this applet, you can explore which assumptions guarantee the existence of global extrema and what can happen when one of these assumptions is not satisfied.

Claim to investigate — Extreme Value Theorem: If \(f\) is continuous on a closed and bounded interval \([a,b]\), then \(f\) attains both a global minimum and a global maximum on \([a,b]\).

Use the examples below to investigate the role of each assumption and whether the assumptions are necessary or merely sufficient.

Select a function and move the finite boundaries \(a\) and \(b\) directly along the \(x\)-axis. You can include or exclude each finite boundary independently and make the domain unbounded to the left or to the right.

Explore:

  1. Select \(f(x)=x\), keep both \(a\) and \(b\) finite, and include both boundaries. Where does \(f\) attain its global minimum and global maximum? What happens when you move \(a\) or \(b\)?
  2. For \(f(x)=x\), exclude first \(a\), then \(b\), and finally both boundaries. Which global extrema cease to exist? Why do the limiting values at excluded boundaries not count as extrema?
  3. Select \(b=+\infty\) while keeping \(a\) included. Is \([a,\infty)\) closed? Is it bounded? Which global extrema does \(f(x)=x\) have? Repeat for \((-\infty,b]\) and \(\mathbb{R}\).
  4. Can the global extrema of \(f(x)=\frac{(x-1)(x+2)(x-2)}{8}\) lie in the interior of a closed and bounded interval? Experiment with different values of \(a\) and \(b\).
  5. Select \(f(x)=|x-1|\) and a domain containing \(x=1\). The function is continuous but not differentiable at \(x=1\). Does it nevertheless attain a global minimum there? Which property is required by the Extreme Value Theorem?
  6. Find an open interval containing \(x=1\) on which \(f(x)=|x-1|\) has a global minimum. Then consider the function on \(\mathbb{R}\). Which global extrema exist? Does failure of the theorem's assumptions imply that extrema cannot exist?
  7. Select the step function on \([-1,1]\), including both boundaries. Why is there no global maximum although the domain is closed and bounded? Which hypothesis is not satisfied?
  8. Summarise the roles of continuity, closedness, and boundedness. Do your experiments show that these assumptions are necessary for global extrema to exist, or that together they provide a sufficient guarantee?
