Monotonie und Vorzeichen der Ableitung

In dieser Ansicht kannst du untersuchen, wie die Steigung der Tangente, das Vorzeichen von \(f'(x)\) und das Monotonieverhalten von \(f\) zusammenhängen.

Gib eine differenzierbare Funktion \(f(x)\) ein und aktualisiere den Graphen. Verschiebe anschliessend \(x_0\) auf der \(x\)-Achse. Die grüne Tangente und der orange Punkt \((x_0,f'(x_0))\) werden dabei laufend aktualisiert. Aus den besuchten Punkten entsteht schrittweise der Graph von \(f'\).

Untersuche:

  1. Welches Vorzeichen hat \(f'(x_0)\), wenn der Graph von \(f\) steigt beziehungsweise fällt?
  2. An welchen Stellen ist die Tangente horizontal? Vergleiche diese Stellen mit den lokalen Extremstellen von \(f\).
  3. Bewege \(x_0\) von links nach rechts und formuliere eine Vermutung über den Graphen von \(f'\). Blende ihn danach vollständig ein.
  4. Untersuche zusätzlich \(f(x)=x^3\). Folgt aus \(f'(x_0)=0\) immer, dass \(f\) bei \(x_0\) ein lokales Extremum besitzt?
  5. Formuliere einen Zusammenhang zwischen dem Vorzeichen von \(f'\) auf einem Intervall und der Monotonie von \(f\) auf diesem Intervall.

Die Tangente hat an \(x_0\) eine positive Steigung. Gilt \(f'(x)>0\) auf einem ganzen Intervall, so ist \(f\) auf diesem Intervall streng wachsend.

Die Tangente hat an \(x_0\) eine negative Steigung. Gilt \(f'(x)<0\) auf einem ganzen Intervall, so ist \(f\) auf diesem Intervall streng fallend.

Die Tangente ist an \(x_0\) horizontal. Aus \(f'(x_0)=0\) allein folgt jedoch noch nicht, dass \(f\) dort ein lokales Extremum besitzt.

Die Ableitung \(f'(x_0)\) ist an dieser Stelle nicht definiert.
